# WebCa

**Настрой вебкамеру один раз — и она такая везде.**

Небольшое нативное приложение для Windows 11: яркость, экспозиция, баланс белого, фокус и всё
остальное, что умеет твоя камера. Настройки держатся в Discord, OBS, Telegram, Teams и любых
других приложениях.

[English version](README.md) · [Как помочь проекту](CONTRIBUTING.md) · [Изменения](CHANGELOG.md)

## Зачем

Настройки камеры в Windows до сих пор спрятаны в окне свойств из начала двухтысячных. Всё, что
там выставлено, живёт до тех пор, пока камеру не откроет другое приложение, её не переподключат или
компьютер не проснётся. WebCa заменяет это окно современным интерфейсом и делает так, чтобы
настройки не слетали.

## Возможности

- **Все параметры камеры** — полные наборы *Video Proc Amp* и *Camera Control*: яркость,
  контрастность, оттенок, насыщенность, резкость, гамма, баланс белого, компенсация подсветки,
  усиление, антимерцание, экспозиция, фокус, зум, панорама и наклон, с автоматическими режимами,
  где камера их поддерживает.
- **Живое превью** во время настройки.
- **Работает во всех приложениях.** Сохраняешь один раз — и Windows сама применяет значения, когда
  любое приложение включает камеру (системный режим), либо это делает агент WebCa в трее.
- **Закрепление значений.** По желанию WebCa отменяет изменения, которые другие приложения вносят
  в настройки камеры.
- **Профили** — например, «День» и «Вечер», — переключаются из окна или из трея.
- **Командная строка и MCP-сервер** для скриптов, Stream Deck и ИИ-ассистентов.
- **Нативно и легко.** Rust и интерфейс, который рисуется на GPU. Светлая и тёмная тема по системе.
  Русский и английский языки.
- **Приватно.** Ни аккаунтов, ни телеметрии. Единственный сетевой запрос — необязательная проверка
  новой версии на GitHub.

## Как это работает

```
              нажимаешь «Сохранить»
                       |
          +------------+-------------+
          |                          |
   системный режим              агент в трее
          |                          |
  хранилище настроек         следит за активностью камеры
  камеры Windows (своё       и применяет профиль, когда
  для каждого пользователя   другое приложение начинает
  и каждой камеры)           трансляцию; с закреплением
          |                  отменяет чужие изменения
          +------------+-------------+
                       |
     Discord / OBS / Telegram / Teams включают камеру
                       |
               настройки уже на месте
```

**Системный режим** использует механизм настроек по умолчанию, который появился в Windows 11 для
её собственной страницы настроек камеры. WebCa регистрируется как приложение-компаньон камеры.
Для этого нужна установленная версия (MSIX) и одно подтверждение прав администратора. После этого
для применения настроек не нужен ни один процесс WebCa.

**Агент в трее** работает и в портативной версии. Пока камера не используется, он почти не
потребляет ресурсов и вмешивается в момент, когда какое-то приложение начинает трансляцию.

Приложения, которые сами выставляют параметры камеры (так умеет, например, OBS), имеют приоритет
над настройками Windows по умолчанию. Включи **«Закрепить значения»**, если хочешь, чтобы WebCa
держала твои.

## Установка

Скачай последний выпуск со страницы **Releases**:

| Пакет | Когда выбрать |
|---|---|
| `WebCa-x.y.z-x64.msix` | Нужен системный режим и автозапуск. Установка двойным щелчком. |
| `WebCa-x.y.z-portable-x64.zip` | Хочется один исполняемый файл. Настройки поддерживает агент в трее. |

Требования: Windows 11 (x64) и UVC-вебкамера. Windows 10 пока не поддерживается — подробности
в [docs/windows-10-gaps.md](docs/windows-10-gaps.md).

## Использование

1. Открой WebCa и подбери значения, глядя на превью.
2. Нажми **«Сохранить»**.
3. По желанию нажми **«Включить системный режим»** (в установленной версии) и подтверди запрос
   Windows.

После закрытия окна WebCa остаётся в области уведомлений. В её меню можно переключить профиль,
включить или выключить закрепление, снова открыть окно и выйти.

### Командная строка

```
webca list                       все параметры с диапазонами и текущими значениями
webca get exposure               текущее значение одного параметра
webca set exposure -6            изменить параметр прямо сейчас
webca set white_balance auto     пусть камера решает сама
webca profiles                   сохранённые профили, активный отмечен *
webca apply Evening              применить сохранённый профиль
```

### MCP-сервер

`webca mcp` работает по протоколу Model Context Protocol через стандартные ввод и вывод, так что
ассистент может читать и менять настройки камеры. Добавь его в конфигурацию MCP-клиента:

```json
{
  "mcpServers": {
    "webca": { "command": "C:\\Path\\To\\webca.exe", "args": ["mcp"] }
  }
}
```

Инструменты: `list_controls`, `get_control`, `set_control`, `reset_control`, `list_profiles`,
`apply_profile`.

## Где хранятся настройки

Профили лежат в `%APPDATA%\WebCa\profiles.toml`. Системные значения по умолчанию хранит Windows,
их можно сбросить в **Параметры › Bluetooth и устройства › Камеры › Сбросить параметры**.
